## Resumen del caso
- **Quién:** Psicól. MaryTere, Psicoterapeuta Gestalt certificada (cédula), 4 años. Querétaro + en línea.
- **Servicios:** Terapia individual. $700 presencial / $600 en línea. L–V 4–7 p.m.
- **Meta:** darse a conocer (awareness) → primeras conversaciones → citas, sin saturar agenda.
- **Restricciones clave:** no muestra rostro · presupuesto pauta ~$2,000/mes · reglas Meta salud.
- **Idea rectora:** marca ilustrada (logo/acuarela) + voz + palabras; honestidad y "invitar, no vender".
